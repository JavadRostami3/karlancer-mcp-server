# راهنمای فارسی Karlancer MCP Server

این پروژه یک **MCP Server غیررسمی برای کارلنسر** است؛ ربطی به تیم رسمی کارلنسر ندارد و برای استفاده روی سرور خودتان منتشر شده است.

**قابلیت‌ها:** اتصال Streamable HTTP + OAuth، پنل فارسی، ورود با کد یک‌بارمصرف کارلنسر، جداسازی حساب کاربران، جست‌وجوی پروژه، آماده‌سازی پروپوزال، مدیریت پیام‌ها و کنترل ارسال مطابق سیاست مالی صاحب حساب.

## راه‌اندازی

پیش‌نیاز: Docker Compose، دامنه دارای HTTPS، و برای توسعه Node.js 24 یا جدیدتر.

~~~bash
git clone https://github.com/JavadRostami3/karlancer-mcp-server.git
cd karlancer-mcp-server
cp .env.example .env
openssl rand -hex 32
~~~

در فایل خصوصی .env این متغیرها را تعیین کنید:

| نام | توضیح |
| --- | --- |
| BASE_URL | آدرس HTTPS سرویس مثل https://mcp.example.com |
| MASTER_KEY | کلید ثابت ۶۴ کاراکتری تولیدشده با openssl |
| OWNER_PHONE_HASH | هش SHA-256 موبایل ده‌رقمی مدیر اول با قالب 9xxxxxxxxx |
| PORT | پیش‌فرض 8940 |
| DB_PATH | مسیر دیتابیس، پیش‌فرض /app/data/state.sqlite |

نمونه دستور ساخت هش را در [README اصلی](../README.md#quick-start) ببینید.

~~~bash
docker compose up -d --build
curl -fsS http://127.0.0.1:18940/healthz
~~~

کانتینر فقط روی لوپ‌بک در دسترس است؛ برای دسترسی اینترنتی باید Reverse Proxy و SSL معتبر تنظیم کنید. پس از آن پنل را از آدرس اصلی باز کنید و حساب کارلنسر را متصل کنید.

## اتصال ChatGPT و دیگر کلاینت‌ها

در بخش MCP کلاینتی که **Streamable HTTP و OAuth** را پشتیبانی می‌کند، این آدرس را وارد کنید:

~~~text
https://mcp.example.com/mcp
~~~

مجوزهای لازم را در مرورگر تأیید کنید. امکان ارسال پیام و پروپوزال به سیاست‌های مالک حساب وابسته است و در ابتدا غیرفعال خواهد بود.

**مهم:** هیچ فایل .env، توکن، کوکی، شماره شخصی، پیام خصوصی یا دیتابیس را در GitHub منتشر نکنید. وضعیت UNKNOWN در ارسال به معنای عدم قطعیت است و نباید کورکورانه ارسال را تکرار کرد.
