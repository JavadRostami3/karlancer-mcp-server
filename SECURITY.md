# Security policy

For vulnerabilities, please use [GitHub private vulnerability reporting](https://github.com/JavadRostami3/karlancer-mcp-server/security/advisories/new) if enabled, or contact the maintainers privately via GitHub. Do not post sensitive exploit details in public issues.

Do not share real OTPs, authorization headers, session cookies, customer communications, private phone numbers or database files. Protect your TLS endpoint, MASTER_KEY and encrypted SQLite backups. Minimize OAuth scopes and maintain owner-controlled sending policies. If a write returns UNKNOWN, check its operation status; never replay blindly.

This unofficial community software is supplied without a security-response SLA or warranty. Operators are responsible for deployments.
